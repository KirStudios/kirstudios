Hello! Welcome to PY-DOS! A project made by me, Kir Studios by myself! It's a program based in Python.

**🤨What the hell is a PY-DOS?:**

PY-DOS or Python Disk Operating System is a Python script that simulates a DOS-based computer with modern features.

**😐Cool, so like... what features are there?:**

You have RAMdrives (drives that use your RAM to store files in RAM)

You have a Command Hub (its like command prompt)

You have Recovery Enviomrent (for recovering PY-DOS)

And you have 'pydos_config.txt', 'pydos_autorun.txt', and 'pydos_imports.txt', config stores username and a variable to do setup or not, autorun stores a python script (in .txt) to auto run when you start PY-DOS and imports store a list of imports that will be loaded when starting up
